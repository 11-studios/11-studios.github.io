# 11_ Studios

11_ Studios Minecraft plugin vitrini.

## GitHub Pages

Doğrudan `https://11-studios.github.io` adresini kullanmak için repository adını **`11-studios.github.io`** yap ve repository'yi **Public** olarak ayarla. Ardından **Settings → Pages** bölümünden `main` dalının `/ (root)` klasörünü yayın kaynağı olarak seç.

Site dosyaları statiktir; public sayfada admin şifresi, kullanıcı parolası, API anahtarı veya token tutulmaz.

## Plugin yönetimi

Plugin kataloğu `plugins.json` dosyasındadır. Güvenli yönetim için site içinde parola tabanlı admin paneli yoktur. Repository yetkisi olan kişiler GitHub üzerinden `plugins.json` dosyasını düzenleyebilir veya **Actions → Manage plugin** iş akışını kullanabilir.

İndirme/satış bağlantıları yalnızca `https://` olmalıdır.
